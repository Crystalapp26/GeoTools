# GeoTools

Free, browser-based GIS and data analysis tools.

GeoTools provides practical utilities for students, GIS professionals, researchers, and anyone working with geographic or tabular data.

## Available tools
- Distance calculator
- NDVI calculator
- Coordinate converter (decimal degrees to DMS)
- CSV quick statistics

## Website
Visit the live GeoTools website to explore the tools.

## Privacy
The tools are designed to process data directly in your browser where possible. Please check the privacy information on the website for details.
